# The libraries this project needs.
# We list only the main ones; the installer automatically pulls in the
# correct supporting pieces for whatever computer you're on (Windows, Mac,
# Linux, with or without a graphics card). This keeps it portable.

supervision        # the "organiser": tracking IDs (ByteTrack), counting, zones
streamlit          # the "dashboard": shows it all in a web page
numpy              # number handling used throughout (also a dependency above)
